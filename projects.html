Agent Test Kit

Regression testing for Agentforce agents · Salesforce unmanaged package

2026

Admins change topics, actions and instructions, and Salesforce ships three releases a year. Agent Test Kit re-runs a suite of test conversations against a live agent and grades every reply, so a regression shows up on a dashboard instead of in front of a customer.

  • Sends each test message to the agent through the generateAiAgentResponse invocable action and records the reply and response time
  • Grades replies three ways: required keywords, forbidden keywords, and an LLM judge (Einstein Models API) that checks a plain-language expected behaviour
  • Built-in starter pack of 8 safety checks: prompt injection, persona hijack, data-leak requests, toxic input, off-topic and harmful requests, and human handoff
  • Runs as Batch Apex with one scenario per batch, so every agent call gets fresh governor limits; nightly runs via a Schedulable
  • Lightning Web Component dashboard to add scenarios, start runs and drill into failures, refreshing live while a run is in progress
  • 9 Apex tests using fake agent and judge clients; packaged and installed in a separate org, where the starter pack passed 8 of 8 against a live service agent
